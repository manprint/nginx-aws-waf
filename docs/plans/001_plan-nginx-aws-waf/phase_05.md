### Node metrics (added to `deploy/vector/node.yaml`)
```yaml
sources:
  m_host: {type: host_metrics, collectors: [cpu, memory, load, filesystem, network], scrape_interval_secs: 15}
  m_nginx: {type: nginx_metrics, endpoints: ["${WAF_NGINX_STATUS_URL}"], scrape_interval_secs: 15}
  m_vector: {type: internal_metrics, scrape_interval_secs: 15}
transforms:
  m_tag: {type: remap, inputs: [m_host, m_nginx, m_vector], source: '.tags.node_id = "${WAF_NODE_ID}"'}
```
- `fwd_central.inputs` gains `m_tag` (rendered forward.yaml).
- The `fwd_none` blackhole also takes `m_tag`.
- `WAF_NGINX_STATUS_URL`: in host mode `http://127.0.0.1:8090/nginx_status`; in bridge mode `http://waf:8090/nginx_status`. The render changes the status server `listen` to `8090` (all interfaces, not published) in bridge mode and keeps `127.0.0.1:8090` in host mode. host_metrics in a container reads `/proc` of the container unless `/proc` and `/sys` of the host are mounted. Mount `/proc:/host/proc:ro` and `/sys:/host/sys:ro`, and set env `PROCFS_ROOT=/host/proc`, `SYSFS_ROOT=/host/sys`.

Central Vector additions:
- the route gets a `metric: {type: is_metric}` output;
- log route conditions become `{type: vrl, source: 'is_string(._t) && ._t == "event"'}` (same for match and hb);
- sink `prom: {type: prometheus_exporter, inputs: [route_t.metric], address: "0.0.0.0:9598", flush_period_secs: 60}`.

- `alerting/contact-points.yaml`: `snippets/grafana-contact-point.yaml` verbatim (minus the VERIFIED line).
- `alerting/policies.yaml`: root policy receiver = that contact point, `group_by: [alertname, site_id]`, `group_wait: 30s`, `group_interval: 5m`, `repeat_interval: 4h`.
- `alerting/rules.yaml`: rendered from the thresholds (below).

Alert rules (folder `WAF`, group `waf`, interval `1m`). Each rule has 3 data entries:
- A: ClickHouse, `queryType: table`, `format: 1`, relativeTimeRange `{from: 600, to: 0}`, returning columns `site_id` (or `node_id`) plus `value`;
- B: `__expr__` reduce last;
- C: `__expr__` threshold gt X.

Settings: `condition: C`, `for: 2m`, `noDataState: OK`, `execErrState: Error`, labels `{severity: warning|critical}`, annotations `{summary: "..."}`.

| uid | title | A SQL | X | severity |
|---|---|---|---|---|
| waf-block-spike | WAF block spike | `SELECT site_id, sum(requests) AS value FROM waf.agg_requests_1m WHERE minute >= now() - INTERVAL 5 MINUTE AND action = 'BLOCK' GROUP BY site_id` | block_spike_per_5m | warning |
| waf-fail | WAF fail events | same with `action = 'FAIL'` | fail_per_5m − 1 (use `gt`, so ≥ 1 fires at default 1) | critical |
| waf-disagree | WAF vs AWS default disagreement | `… AND action != aws_default_action …` | disagreement_per_5m | warning |
| waf-node-silent | WAF node silent | `SELECT node_id, dateDiff('second', max(ts), now64(3)) AS value FROM waf.heartbeats GROUP BY node_id` | node_silent_min×60 | critical |
| waf-ingest-lag | WAF ingest lag | `SELECT site_id, dateDiff('second', max(ts), now64(3)) AS value FROM waf.events WHERE ts > now() - INTERVAL 1 DAY GROUP BY site_id` | ingest_lag_min×60 | warning |

For waf-ingest-lag, set `noDataState: OK`. The annotation states "no traffic or ingest stalled; check node-silent first".

### Dashboards (`deploy/grafana/dashboards/*.json`, generated by `scripts/gen-dashboards.py` from `deploy/grafana/panels.py`)
- **Generator:**
  - stdlib Python 3. Each panel is a dict `{title, type: timeseries|table|stat|barchart|piechart, ds: ch|prom, sql|expr, w, h, unit?}`. Layout is a row-major grid, 24 columns wide.
  - Targets:
    - ClickHouse: `{"datasource": {"type": "grafana-clickhouse-datasource", "uid": "ch"}, "editorType": "sql", "queryType": "timeseries" if type == timeseries else "table", "format": 0 if timeseries else 1, "rawSql": sql, "refId": "A"}`;
    - Prometheus: `{"datasource": {"type": "prometheus", "uid": "prom"}, "expr": expr, "refId": "A"}`.
  - Dashboard: `{"uid", "title", "schemaVersion": 39, "time": {"from": "now-6h", "to": "now"}, "refresh": "30s", "templating": {...}, "panels": [...]}`.
  - Variable `site`: query `SELECT DISTINCT site_id FROM waf.agg_requests_1m WHERE minute > now() - INTERVAL 30 DAY ORDER BY site_id`, multi, includeAll, `allValue: "__all__"`.
  - Site filter fragment: `('__all__' IN (${site:singlequote}) OR site_id IN (${site:singlequote}))`.
  - Time filter macros: `$__timeFilter(ts)` / `$__timeFilter(minute)`; bucket with `$__timeInterval(ts)`.
- **Dashboards and panels:**
  1. **`waf-overview`** "WAF Overview" (agg tables):
     - stats: total requests, blocked, block %, fail, AWS-default blocks, disagreements;
     - timeseries: requests by action (stacked); blocks by site; status_class;
     - tables: top terminating rules (matches, post_terminating=0); top sites by blocks.
  2. **`waf-tuning`** "WAF Rules & Tuning":
     - table: rules with configured_action COUNT (would-block candidates) by site;
     - timeseries: matches per rule (top 10);
     - table: disagreements `action` vs `aws_default_action` by site/user_class;
     - table: top paths for counted rules (from matches);
     - barchart: matches by user_class.
  3. **`waf-explorer`** "WAF Request Explorer" (events):
     - variables `ip` (textbox), `rule` (textbox), `action` (custom ALLOW,BLOCK,FAIL, includeAll);
     - table: last 500 events (ts, site, ip, country, method, path, status, action, shadow_action, terminating_rule, request_id);
     - table: matches for `$rid` (textbox var);
     - piechart: country; table: top ASN.
  4. **`waf-nodes`** "WAF Nodes Health":
     - table: heartbeats (node, version, config_rev, last seen, age s);
     - Prometheus timeseries: `rate(nginx_requests_total[1m])` by node_id, `nginx_connections_active`, `host_cpu_seconds_total` busy % by node_id, `host_memory_available_bytes`, `vector_buffer_byte_size` and `vector_component_errors_total` rate, `ClickHouseMetrics_Query` (clickhouse job).
  - If a metric name differs, look it up via `curl prometheus:9090/api/v1/label/__name__/values` and use the actual name. Record it.
